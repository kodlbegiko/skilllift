# SkillLift 中文摘要

> 小模型，真實能力。

**目前狀態：研究藍圖，尚未實作。** 此專案尚無可安裝版本、正式評測成果或經驗證的安全保證。

SkillLift 是一個預計開源、本地優先的 AI 技能執行與評測框架。核心研究目標是在不依賴雲端模型 API 的前提下，讓小型語言模型透過結構化 Skill、有限決策、確定性工具、權限控管、獨立驗證與錯誤恢復，完成真實電腦任務。

第一階段以 Apple Silicon macOS、24GB 統一記憶體為參考平台，優先使用 Python、Ollama、本機隔離測試資料夾與可重現的任務評測。後續才擴展 macOS Accessibility 操作、MLX、本地執行追蹤與 SDK。

主要研究問題：固定模型、工具、硬體與預算後，結構化技能執行是否比一般工具呼叫更可靠？哪些任務不需要模型？驗證與恢復的獨立貢獻是多少？是否有小模型在特定任務上達到較大模型的表現？任何優勢都必須透過公平對照實驗證明。

與一般 Agent Skills 的差異假設：不是把更多文字塞給模型，而是把可確定的步驟交給程式，模型只負責必要的語意判斷。與 Computer Use Driver 的關係是互補，不重造既有底層工具。

開發分為可行性研究、核心 Runtime、有限 Computer Use、Benchmark、開源發布五階段。先完成一條從本地模型到獨立驗證的垂直流程，再逐步擴充。所有真實電腦操作必須有明確的邊界；第一版不支援任意 Shell、個人帳號操作、付款、刪除或外部傳送。
